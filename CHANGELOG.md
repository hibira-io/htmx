# Changelog

## 0.1.0

First release: `hx-ext="hibira"` for htmx 2 and htmx 4. `hibira-connect`,
`hibira-channel`, `hibira-swap` (with `hx-swap`, `hx-target`, `hx-select`
and out-of-band swaps), `hx-trigger="hibira:event"`, private channel
authorization with `hx-headers`, `hibira-state` on the connect element,
`hibira:before-swap` / `after-swap` / `state` / `error` events, Laravel
Echo's connection reused when present, and a script-tag build at
`dist/hibira.min.js`.
